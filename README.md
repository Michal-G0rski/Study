# Summary
This curriculum is my **personal roadmap** to:
- Learn programming and computer science fundamentals.  
- Build skills to work as a **remote developer**.  
- Transition into **web application security, pentesting, and cloud security**.  

It is based on [OSSU Computer Science](https://github.com/ossu/computer-science) but adapted with:
- **Python-first focus** (instead of Java/Scheme-heavy parts).  
- More emphasis on **security, web apps, and cloud**.  
- A **shorter, career-oriented path** (2–3 years).  

---

# Curriculum

## Prerequisites
- High school math (algebra, basic probability)  
- English comprehension  
- Curiosity and persistence 🚀  

---

## Intro
- **Systematic Program Design** (do all)  
- **Python OOP & Design**  
  - *Fluent Python* (book)  
  - Corey Schafer OOP playlist (YouTube)  
  - ArjanCodes – Design Patterns in Python (YouTube)  

---

## Core
### Programming & Software
- Programming Languages (OSSU – do all)  
- Software Architecture (free part only)  
- Debugging & Testing (from advanced programming)  

### Math
- All OSSU core math courses (calculus, linear algebra, probability)  

### Systems
- **The Missing Semester** (Linux, Git, tooling)  
- **Core Systems (light)**  
  - CrashCourse Computer Science (YouTube)  
  - *Code* (Charles Petzold, book)  
  - *Crafting Interpreters* (only first half)  
- **Operating Systems: Three Easy Pieces** (do all)  
- **Computer Networking: A Top-Down Approach** (do all)  

### Theory
- All OSSU core theory courses  
- Advanced: Theory of Computation  

### Security
- All OSSU core security  
- All OSSU advanced information security  

### Applications
- Databases, compilers, software engineering (skip graphics + ML)  

---

## Advanced
- Advanced Math (all OSSU set)  
- Optional: Cloud fundamentals (AWS or Azure free courses)  
- Security practice in parallel:  
  - PortSwigger Web Security Academy (free labs)  
  - OWASP Top 10 (study guide)  
  - TryHackMe / HackTheBox (hands-on)  

---

# Final Project
[Fullstackopen](https://fullstackopen.com/en/) — build a full-stack web app.  
- Deploy it to the cloud (AWS/Azure/Render/Heroku).  
- Add security features (auth, role-based access, input validation).  
- Document it in a GitHub portfolio.
