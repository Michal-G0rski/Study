## Rules for a week that goes wrong

- **No personal Azure resource is ever created.** Sentinel is learned from the free modules and practised as KQL in the demo environment; everything that has to persist goes into Wazuh and Git instead.
- The detection library is the deliverable, not the individual rules. A rule that only exists in one engine is half the point of this month.
- The demo environment is read-only and shared, so it holds nothing of yours — save every query in Git as you write it, and build the parts that matter as Wazuh rules.
