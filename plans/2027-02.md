# February 2027 — Stage 2, Microsoft Sentinel & KQL Begin

Month 5 of [the plan](../README.md). **15 h/week: 2.5 h/day, Monday to Saturday, Sunday off.**

Three clean weeks, 45 hours. February 2027 begins on a Monday. This is the first half of a six-week Sentinel/KQL block — the other three weeks are the start of [March](2027-03.md). Splitting it across two files is deliberate: one topic per week, not four KQL operator families crammed into four days the way the old plan did it.

**No personal Azure subscription this month, and none for the rest of the plan.** Sentinel and KQL are learned entirely on [Microsoft Learn's own free, pre-provisioned sandbox environments](https://learn.microsoft.com/en-us/training/paths/sc-200-configure-azure-sentinel-environment/) — they run on Microsoft's temporary subscription, time-boxed per module, with nothing to bill and nothing to forget to tear down. Anything you build that needs to survive past the sandbox's lifetime — the detection library, the KQL cheat sheet — goes into [Wazuh](https://wazuh.com/) instead, starting this month, so the portfolio never depends on a resource someone else's clock can delete or a subscription that can generate a surprise invoice.

## Sources in use this month

- [Microsoft Sentinel learning path](https://learn.microsoft.com/en-us/training/paths/sc-200-configure-azure-sentinel-environment/) — free, official Microsoft Learn modules, run entirely in their built-in sandbox
- [Must Learn KQL (Rod Trent)](https://github.com/rod-trent/MustLearnKQL) — the practical KQL reference
- [LetsDefend](https://letsdefend.io/) — free blue-team labs (start alongside)
- [Wazuh](https://wazuh.com/) — self-hosted, open-source SIEM/XDR (OpenSearch-based), installed this month as the home for every detection you want to keep past the Learn sandbox's lifetime

## Rules for a week that goes wrong

- The SIEM hours are protected. This block runs through mid-March; nothing later in the plan works without it.
- **Every KQL query is written by you, not pasted.** The cheat sheet is the proof.
- **No personal Azure resource is ever created this month.** If a Learn module asks for one, that module is skipped and substituted — the sandbox always covers the SC-200 syllabus.
- If LetsDefend is slow, substitute with CyberDefenders or public alert sets — but do the triage writing.
